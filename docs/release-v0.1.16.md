# EasyNotice v0.1.16

OpenWrt 首次接入优先推荐微信推送（wechatpush），页面与手册明确区分它与全能推送 PushBot。已有 PushBot 配置继续保留，无需迁移；微信推送暂通过通用 Webhook 接入，尚无专用一键模板。

- 修正 PushBot 排障指引：仅凭证检查报错时使用兼容命令；手动测试不能代替真实设备事件验证。
- 修复绿联入口类型异常导致后台跳过轮询，启动时自动纠正已有采集器入口。
- 修复保存图片、链接等局部设置时意外清空出口、重置入口类型和其他未提交字段的问题。
- 增加脱敏诊断导出与绿联采集记录，便于区分采集、入队和投递失败。

影响范围：OpenWrt 操作说明、通知入口配置保存、绿联后台采集与诊断。不会修改路由器设置。建议升级前备份数据目录；旧版本已经清空的出口需重新勾选保存，失败消息不会自动补发。

验证：类型检查与 42 项自动测试通过。绿联恢复轮询和后续真实通知已得到用户验证；旧版 PushBot 漏检原因尚未完全确定，本版不宣称修复其设备检测。镜像由 GitHub Actions 构建并执行容器检查。
